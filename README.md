# mistqkw — portfolio

[PL](#polski) · [EN](#english)

Live: https://mistqkw.github.io/freelance-portfolio/

## Polski

Strona portfolio **mistqkw**: landing page z animacją (GSAP + ScrollTrigger, płynny scroll), przełącznik języka PL/EN, motyw jasny i ciemny, trzy projekty demo, pakiety z cenami i opis współpracy.

Projekty demo (firmy są fikcyjne):

- [Brzytwa & Cień — barbershop](https://mistqkw.github.io/demo-barber/) · [kod](https://github.com/mistqkw/demo-barber)
- [Ziarno i Para — kawiarnia](https://mistqkw.github.io/demo-cafe/) · [kod](https://github.com/mistqkw/demo-cafe)
- [AquaLinia — myjnia ręczna](https://mistqkw.github.io/demo-carwash/) · [kod](https://github.com/mistqkw/demo-carwash)

### Uruchomienie lokalnie

```bash
python -m http.server 8000
```

Następnie otwórz http://localhost:8000.

### Dane kontaktowe

W sekcji „Kontakt” w `index.html` zamień zaślepki `[TWÓJ_EMAIL]`, `[@TWÓJ_NICK]`, `[LINK_UPWORK]`, `[LINK_KWORK]` na prawdziwe dane (nie są częścią tłumaczeń, więc wystarczy jedna zmiana w HTML).

## English

The **mistqkw** portfolio page: an animated landing page (GSAP + ScrollTrigger, smooth scrolling), PL/EN language switch, light and dark theme, three demo projects, priced packages and a description of the workflow.

Demo projects (the businesses are fictional): see the links above.

### Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

### Contact details

In the "Contact" section of `index.html`, replace the placeholders `[TWÓJ_EMAIL]`, `[@TWÓJ_NICK]`, `[LINK_UPWORK]` and `[LINK_KWORK]` with your real details. They are not part of the translations, so one edit in the HTML is enough.
